# 📦 Inventory Management REST API

A full-stack Inventory Management REST API built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). This application allows users to perform complete CRUD (Create, Read, Update, Delete) operations for inventory products through a clean RESTful API and React-based frontend.

---

## 🚀 Features

- ✅ Add New Products
- ✅ View All Products
- ✅ Update Existing Products
- ✅ Delete Products
- ✅ RESTful API Architecture
- ✅ MongoDB Database Integration
- ✅ React Frontend
- ✅ Express.js Backend
- ✅ JSON Data Exchange
- ✅ Error Handling

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/2005-mayank/inventory-management-rest-api.git
```

### Open Project

```bash
cd inventory-management-rest-api
```

### Install Dependencies

```bash
npm install
```

### Start Backend

```bash
npm run dev
```

---

# 📌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/products | Get All Products |
| GET | /api/products/:id | Get Product By ID |
| POST | /api/products | Add Product |
| PUT | /api/products/:id | Update Product |
| DELETE | /api/products/:id | Delete Product |
